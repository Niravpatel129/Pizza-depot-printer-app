# About Pizza Depot Printer App

Pizza Depot Printer App is an Electron tray application that listens for receipt-print requests and sends them to local thermal printers. It includes native printer integration, packaging, auto-update support, and automated tests around key settings behavior.

For setup and execution, see [`run_instruction.md`](./run_instruction.md). For the broader project overview, see [`README.md`](./README.md).
